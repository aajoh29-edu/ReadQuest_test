# ReadQuest API contract

The complete request/response schemas, validation constraints, status codes and methods are in [openapi.json](openapi.json), generated by `python scripts/export_contract.py`. Paths below are backend paths; the same-origin frontend prefixes them with `/api`. Dates are ISO 8601 UTC; IDs are UUID. Inputs reject unknown fields except the preserved development demo contract. Errors use `{"detail": "safe message"}` or FastAPI's structured 422 validation details. Database conflict: 409; unavailable database: 503. Auth failures: 401; wrong role/origin: 403; inaccessible child/class/activity: 404. List responses are arrays; empty arrays are valid. A null recommendation means no eligible candidate, not an error.

| Method | Route | Input | Output | Auth and role |
|---|---|---|---|---|
| GET | /health, /ready | none | HealthResponse | Public |
| POST | /auth/login | LoginInput: email,password | UserView + HttpOnly session cookie | Public; origin and throttle checked |
| GET | /auth/me | none | UserView | Active session |
| POST | /auth/logout | none | 204; cookie cleared | Active session |
| POST | /auth/password | PasswordInput: current_password,new_password | 204; all sessions revoked | Active session |
| GET | /children | none | ChildView[] | Any role; relationship-scoped |
| POST | /children | ChildInput: email,password,display_name,grade_level? | ChildView; 201 | Parent (automatically linked), admin |
| GET | /children/{id}/progress | none | MasteryView[] | Own/guardian/enrolled-teacher/admin |
| POST | /children/{id}/recommendations | none | RecommendationView or null | Same scope; stores served audit record |
| GET | /lessons | none | LessonView[] | Active session; published only |
| GET | /activities | none | ActivityView[] without answer key | Active session; fully published only |
| GET | /activities/{id} | none | ActivityView without answer key | Active session |
| POST | /attempts | AttemptInput: activity_id,selected_index,response_ms? | AttemptView: attempt_id,is_correct,mastery[],recommendation?; 201 | Child; identity, level, correctness and time server-authored |
| GET | /classes | none | ClassView[] | Teacher-owned or admin-all |
| POST | /classes | ClassInput: name | ClassView; 201 | Teacher; creates own class |
| PATCH | /classes/{id} | ClassStatusInput: status | ClassView | Owner teacher/admin |
| GET | /classes/{id}/children | none | ChildView[] | Owner teacher/admin |
| POST | /children/{id}/enrollments | JoinInput: join_code | ClassView; 201 | Linked guardian/admin |
| DELETE | /classes/{id}/children/{child_id} | none | 204; enrollment marked removed | Linked guardian/owner teacher/admin |
| GET | /admin/users | none | UserView[] | Admin |
| POST | /admin/users | UserInput: email,password,role,display_name?,grade_level? | UserView; 201 | Admin; child role requires display_name |
| PATCH | /admin/users/{id} | StatusInput: status | UserView; revokes sessions | Admin; cannot change own status |
| GET, POST | /admin/skills | SkillInput for POST | SkillView[] / SkillView; 201 | Admin |
| PUT | /admin/skills/{id} | SkillInput | SkillView | Admin |
| GET, POST | /admin/lessons | LessonInput for POST | LessonView[] / LessonView; 201 | Admin |
| PUT | /admin/lessons/{id} | LessonInput | LessonView | Admin |
| GET, POST | /admin/activities | ActivityInput for POST | ActivityView[] / ActivityView with answer keys; 201 | Admin |
| PUT | /admin/activities/{id} | ActivityInput | ActivityView with answer key | Admin; content/mappings immutable after evidence |
| GET | /demo/activities | none | ActivityResponse[] with development answer key | Anonymous, development only |
| POST | /demo/attempts | SubmitAttemptRequest: activity_id,is_correct,selected_index?,response_ms? | SubmitAttemptResponse | Anonymous fixed seeded reader, development only |

MasteryView includes skill_id, skill_name, score, band, confidence, attempt_count (last-ten window), and last_practiced_at. Unassessed published skills are present with zero samples and the `unassessed` display band. RecommendationView includes an answer-free activity, normalized priority_score, stable reason_code, child-friendly explanation and reason_details. ActivityInput includes type-specific content (2–8 choices, correct_index, optional passage), level 1–10 and unique skills with positive weights totaling one. Read-and-answer requires a passage. No password hash, raw session token or answer key appears in production learner responses.

Example submission: `{"activity_id":"00000000-0000-0000-0000-000000000311","selected_index":0,"response_ms":2400}`. Client-supplied `child_id`, `is_correct`, event time or learner level is rejected. Schema edits require regenerating the JSON and re-running API tests.
