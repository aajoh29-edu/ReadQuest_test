# ReadQuest data dictionary — ERD v1

This is the logical schema for review. PostgreSQL types and constraint names will be finalized during Build Process 3.

## Shared conventions

| Convention | Decision |
|---|---|
| Primary keys | UUID generated by the application or PostgreSQL; decision tracked in ADR-0002. |
| Time | `timestamptz` in UTC. API responses use ISO 8601. |
| Audit columns | Mutable entities receive `created_at` and `updated_at`; append-only evidence receives `created_at`/`occurred_at`. |
| Scores | Store normalized values from 0.0000 to 1.0000 using `numeric(5,4)`. |
| Names | Database uses `snake_case`; classes use singular Python names. |
| Deactivation | Users/content use status fields instead of routine hard deletion. |

## users

| Field | Type | Null? | Rule |
|---|---|---:|---|
| id | uuid | No | Primary key. |
| email | citext | No | Unique normalized login email. |
| password_hash | varchar(255) | No | Never returned by API or logged. |
| role | user_role enum | No | `child`, `parent`, `teacher`, `admin`. |
| status | user_status enum | No | `active`, `disabled`, `pending`; default `active`. |
| created_at | timestamptz | No | Default current UTC time. |
| updated_at | timestamptz | No | Updated on mutation. |

**Indexes:** unique `email`; `(role, status)` for administration.

## child_profiles

| Field | Type | Null? | Rule |
|---|---|---:|---|
| id | uuid | No | Primary key. |
| user_id | uuid | No | Unique FK → users.id; referenced user must have child role (service rule). |
| display_name | varchar(80) | No | Child-facing name; avoid unnecessary legal-name collection. |
| grade_level | smallint | Yes | Check 0–12 when supplied. |
| current_level | smallint | No | Check 1–10; default 1. |
| created_at | timestamptz | No | Default current UTC time. |

**Indexes:** unique `user_id`.

## guardian_children

| Field | Type | Null? | Rule |
|---|---|---:|---|
| guardian_id | uuid | No | Composite PK; FK → users.id. Parent role enforced by service. |
| child_id | uuid | No | Composite PK; FK → child_profiles.id. |
| relationship_label | varchar(40) | Yes | Optional display label such as parent/guardian. |
| created_at | timestamptz | No | Default current UTC time. |

**Indexes:** primary `(guardian_id, child_id)`; secondary `child_id` for reverse lookup.

## classes

| Field | Type | Null? | Rule |
|---|---|---:|---|
| id | uuid | No | Primary key. |
| teacher_id | uuid | No | FK → users.id; teacher role enforced by service. |
| name | varchar(120) | No | Required classroom name. |
| join_code | varchar(20) | No | Unique, random, non-sequential code. |
| status | class_status enum | No | `active`, `archived`; default `active`. |
| created_at | timestamptz | No | Default current UTC time. |

**Indexes:** unique `join_code`; `(teacher_id, status)`.

## enrollments

| Field | Type | Null? | Rule |
|---|---|---:|---|
| class_id | uuid | No | Composite PK; FK → classes.id. |
| child_id | uuid | No | Composite PK; FK → child_profiles.id. |
| enrolled_at | timestamptz | No | Default current UTC time. |
| status | enrollment_status enum | No | `active`, `removed`; default `active`. |

**Indexes:** primary `(class_id, child_id)`; `(child_id, status)`.

## skills

| Field | Type | Null? | Rule |
|---|---|---:|---|
| id | uuid | No | Primary key. |
| code | varchar(50) | No | Unique stable code, e.g. `PHONICS_SHORT_A`. |
| name | varchar(120) | No | Human-readable skill name. |
| category | varchar(60) | No | Example: phonics, sight words, comprehension. |
| level | smallint | No | Check 1–10. |
| status | content_status enum | No | `draft`, `published`, `archived`. |

**Indexes:** unique `code`; `(category, level, status)`.

## lessons

| Field | Type | Null? | Rule |
|---|---|---:|---|
| id | uuid | No | Primary key. |
| title | varchar(160) | No | Required. |
| description | text | Yes | Short instructional summary. |
| sequence | integer | No | Check ≥ 0; unique among active curriculum if team requires global ordering. |
| status | content_status enum | No | `draft`, `published`, `archived`. |
| created_at / updated_at | timestamptz | No | Audit timestamps. |

**Indexes:** `(status, sequence)`.

## activities

| Field | Type | Null? | Rule |
|---|---|---:|---|
| id | uuid | No | Primary key. |
| lesson_id | uuid | No | FK → lessons.id. |
| title | varchar(160) | No | Required. |
| activity_type | activity_type enum | No | Initial values: `multiple_choice`, `word_match`, `read_and_answer`. |
| prompt | text | No | Learner-facing prompt. |
| content | jsonb | No | Type-specific choices/media references; validated by application schema. |
| difficulty | smallint | No | Check 1–10. |
| sequence | integer | No | Check ≥ 0; unique per lesson. |
| status | content_status enum | No | `draft`, `published`, `archived`. |

**Constraints/indexes:** unique `(lesson_id, sequence)`; `(status, difficulty)`.

## activity_skills

| Field | Type | Null? | Rule |
|---|---|---:|---|
| activity_id | uuid | No | Composite PK; FK → activities.id. |
| skill_id | uuid | No | Composite PK; FK → skills.id. |
| weight | numeric(4,3) | No | Check `0 < weight <= 1`; weights per activity should total 1 (service validation). |

**Indexes:** primary `(activity_id, skill_id)`; secondary `skill_id` for recommendation lookup.

## attempts

| Field | Type | Null? | Rule |
|---|---|---:|---|
| id | uuid | No | Primary key. |
| child_id | uuid | No | FK → child_profiles.id. |
| activity_id | uuid | No | FK → activities.id. |
| is_correct | boolean | No | MVP scoring input. |
| response_ms | integer | Yes | Check `0 <= response_ms <= 3600000`. Not part of mastery score in MVP. |
| answer | jsonb | Yes | Minimal response evidence; must not contain secrets. |
| occurred_at | timestamptz | No | Client event time validated against acceptable bounds. |
| created_at | timestamptz | No | Server persistence time. |

**Indexes:** `(child_id, occurred_at DESC)`; `(child_id, activity_id)`; `activity_id`.

## skill_mastery

| Field | Type | Null? | Rule |
|---|---|---:|---|
| child_id | uuid | No | Composite PK; FK → child_profiles.id. |
| skill_id | uuid | No | Composite PK; FK → skills.id. |
| score | numeric(5,4) | No | Check 0–1. |
| band | mastery_band enum | No | `high_priority`, `additional_practice`, `normal_review`, `mastered`. |
| confidence | mastery_confidence enum | No | `low`, `medium`, `high`; based on attempt count. |
| attempt_count | integer | No | Check ≥ 0. |
| last_practiced_at | timestamptz | Yes | Null means unassessed. |
| algorithm_version | varchar(30) | No | Example: `mastery-v1`. |
| version | integer | No | Optimistic concurrency counter, default 1. |
| updated_at | timestamptz | No | Last calculation time. |

**Indexes:** primary `(child_id, skill_id)`; `(child_id, band)`; `(skill_id, score)` for teacher reporting.

## recommendations

| Field | Type | Null? | Rule |
|---|---|---:|---|
| id | uuid | No | Primary key. |
| child_id | uuid | No | FK → child_profiles.id. |
| activity_id | uuid | No | FK → activities.id. |
| triggering_attempt_id | uuid | Yes | FK → attempts.id; null for on-demand recommendation. |
| priority_score | numeric(5,4) | No | Check 0–1. |
| reason_code | varchar(50) | No | Stable machine-readable explanation. |
| reason_details | jsonb | No | Component scores and supporting skill IDs. |
| algorithm_version | varchar(30) | No | Example: `recommendation-v1`. |
| status | recommendation_status enum | No | `served`, `accepted`, `dismissed`, `expired`. |
| created_at | timestamptz | No | Default current UTC time. |

**Indexes:** `(child_id, created_at DESC)`; `(child_id, status)`; `triggering_attempt_id`.
